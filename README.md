# AeroLume

AeroLume is an Android flight-tracking prototype with a polished radar-style interface. It uses flight data, adaptive layouts, saved flights, search, detail screens, and a MapLibre-powered map experience. The current data is demo only.

## Features

- Radar-style flight map UI
- Demo flight catalog with routes, aircraft, airports, altitude, speed, and delay data
- Search, saved flights, flight detail, settings, and radar screens
- Adaptive phone and tablet workspace layouts
- Map utility components and custom map styling
- In-memory and fake data services for prototype development

## Tech Stack

- Kotlin
- Android Gradle Plugin
- Jetpack Compose
- Material 3
- Navigation Compose
- MapLibre Android
- Kotlin Coroutines

## Getting Started

1. Open the project in Android Studio.
2. Let Gradle sync the project.
3. Run the app on an emulator or Android device.

From the command line:

```bash
./gradlew assembleDebug
```

## Notes

Generated build outputs, local Android SDK paths, and debug APK files are ignored by Git.
